RMSNorm
均方根层归一化

RMSNorm 是 LayerNorm 的简化版——去掉均值中心化，只做尺度归一化。Llama、Mistral、Gemma 等现代大模型全部采用 RMSNorm 替代 LayerNorm，效果相近而计算更快。

1  为什么需要归一化

深层神经网络训练时面临一个问题：每一层的输出分布会随参数更新不断漂移，导致后续层的输入分布不稳定。这被称为内部协变量偏移（Internal Covariate Shift）。

直观来说，如果某一层的激活值突然变得很大（比如均值从 0 漂移到 10，标准差从 1 变成 5），下一层接收到这些值时，梯度会变得非常大或非常小，训练不稳定。

具体危害：激活值尺度过大 → 梯度爆炸；激活值方差过小 → 梯度消失。归一化操作把激活值的尺度控制在合理范围，让每一层的输入分布保持相对稳定。

LayerNorm 和 RMSNorm 都是在特征维度上做归一化——对单个 token 的所有特征维度进行标准化，而不是像 BatchNorm 那样对一个 batch 里同一特征位置归一化。

2  LayerNorm 回顾

给定一个 $d$ 维向量 $\mathbf{x}$，LayerNorm 分两步：先中心化（减均值），再缩放（除标准差），最后乘可学习参数：

$$\mu = \frac{1}{d}\sum_{i=1}^d x_i \qquad \sigma = \sqrt{\frac{1}{d}\sum_{i=1}^d (x_i-\mu)^2 + \varepsilon}$$ $$\text{LayerNorm}(\mathbf{x}) = \frac{\mathbf{x} - \mu}{\sigma} \cdot \gamma + \beta$$
γ（缩放）和 β（偏移）是可学习参数；ε 防止除零

LayerNorm 有两个可学习参数：$\gamma$（scale）和 $\beta$（shift）。它做了两件事：把分布中心移到 0（减均值），再把方差归一化到 1（除标准差）。

3  RMSNorm：去掉均值中心化

RMSNorm 的出发点是：中心化（减均值）对训练稳定性的贡献其实不大，真正重要的是控制激活值的尺度（Scale）。所以直接去掉减均值这一步，只保留尺度归一化：

$$\text{RMS}(\mathbf{x}) = \sqrt{\frac{1}{d}\sum_{i=1}^d x_i^2}$$ $$\text{RMSNorm}(\mathbf{x}) = \frac{\mathbf{x}}{\text{RMS}(\mathbf{x})} \cdot \gamma$$
只有 γ 一个可学习参数，没有 β；不减均值，直接除以 RMS
LayerNorm 做了什么
1计算均值 $\mu$
2减均值（中心化）
3计算标准差 $\sigma$
4除标准差（缩放）
5乘 $\gamma$，加 $\beta$
RMSNorm 做了什么
1计算均值 $\mu$
2减均值（中心化）
1计算 RMS（均方根）
2除 RMS（尺度归一化）
3乘 $\gamma$（无 $\beta$）
为什么去掉中心化依然有效？RMS 归一化后，向量的模长（L2 范数）被控制为 $\sqrt{d}$，各维度的尺度统一。尽管均值不为 0，但激活值尺度稳定这个目标已经达到，模型照样能正常训练。

5  分布变换可视化

RMSNorm 如何改变一批激活值的分布。输入是带有均值偏移和方差的真实激活分布，输出的尺度被控制在 $\gamma$ 倍单位尺度附近。

交互 · 输入 vs 输出分布

橙色 = 输入分布（有均值偏移，方差较大）；绿色 = RMSNorm 后的分布（尺度归一化，均值不一定为 0）；蓝色虚线 = LayerNorm 后（均值强制为 0）

注意均值不为 0：RMSNorm 后输出的均值通常不为 0（除非输入均值恰好为 0）。这和 LayerNorm 不同——LayerNorm 会把均值强制归零。实验表明这个差异对大多数任务影响很小。

6  与 LayerNorm 的全面对比

图示 · 计算量与效果对比

左：每个 token 的归一化计算步骤数量对比；右：归一化后的分布特性对比

LayerNorm

• 需要计算均值和方差，两次遍历特征维度

• 输出均值严格为 0

• 两个可学习参数 γ 和 β

用于：BERT、GPT-2、T5 等早期模型

RMSNorm

• 只需计算均方根，一次遍历

• 输出均值不强制为 0

• 一个可学习参数 γ（无 β）

用于：LLaMA、Mistral、Gemma、Qwen 等

为什么现代大模型更偏好 RMSNorm？在大模型（数十亿参数）训练中，归一化操作会被调用数百万次。RMSNorm 省去了均值计算，理论上节省约 7% 的归一化计算量。对于超大规模训练，这个节省是实质性的。同时论文表明性能没有明显下降。
