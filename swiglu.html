SwiGLU FFN
门控前馈网络

SwiGLU 是 Transformer FFN 层的改进版——用 Swish 激活函数配合门控机制（GLU），让网络能动态地"选择性"传递特征。LLaMA、PaLM、GPT-4 等模型均使用 SwiGLU 替代原始的 ReLU FFN。

1  标准 FFN 回顾

原始 Transformer 的前馈层由两个线性变换和一个 ReLU 激活组成：

$$\text{FFN}(x) = \max(0,\; xW_1 + b_1) W_2 + b_2$$
先升维（×4），ReLU 激活，再降维（÷4）

ReLU 把负值直接截断为 0。问题是：这种硬截断丢弃了所有负数激活的信息，导致"神经元死亡"（负值区域梯度为 0，参数停止更新）。

图示 · 标准 FFN 结构

蓝色 = 线性变换；橙色 = ReLU 激活（截断负值）。整条路径是单分支的。

2  GLU：门控线性单元

GLU（Gated Linear Unit）用两条并行的线性变换，其中一条经过 sigmoid 变成 0~1 的门控信号，与另一条做逐元素乘法：

$$\text{GLU}(x, W, V) = (xW) \odot \sigma(xV)$$
$\odot$ = 逐元素乘；$\sigma$ = sigmoid；门控信号决定哪些特征被"放行"

门控机制的直觉：$\sigma(xV)$ 是一个 0~1 之间的"开关"向量。当某个维度的门控值接近 1，对应的特征完整通过；接近 0，特征被抑制。模型能动态学习哪些信息对当前上下文有用。

为什么叫"门控"：就像水闸控制流量，$\sigma(xV)$ 的每个维度独立控制对应特征维度的流通量。不同的输入 $x$ 会产生不同的门控信号，实现输入相关的自适应特征选择。

3  Swish 激活函数

SwiGLU 用 Swish 替代 GLU 里的 sigmoid 门控。Swish 定义为：

$$\text{Swish}(x) = x \cdot \sigma(x) = \frac{x}{1 + e^{-x}}$$
自门控（self-gated）：用 x 自己的值来决定保留多少 x

Swish 相比 ReLU 的优势：在负值区域有小的非零输出（平滑过渡），梯度不会突然变 0；在正值区域近似线性，不压缩大的正值。

交互 · 激活函数形状

蓝 = ReLU；橙 = GELU；紫 = Swish（SiLU）。竖线 = 当前输入值 x。

4  SwiGLU 完整结构

把 Swish 代入 GLU，得到 SwiGLU：

$$\text{SwiGLU}(x, W_1, W_2, W_3) = \text{Swish}(xW_1) \odot (xW_2)$$ $$\text{FFN}_{\text{SwiGLU}}(x) = \text{SwiGLU}(x, W_1, W_2) \cdot W_3$$
三个权重矩阵 $W_1,W_2,W_3$；$W_1$ 生成门控分支，$W_2$ 生成内容分支，$W_3$ 降维
图示 · SwiGLU FFN 结构对比

上 = 标准 FFN（单分支，ReLU）；下 = SwiGLU（双分支，门控相乘）

参数量变化：标准 FFN 有 2 个权重矩阵（$W_1, W_2$），SwiGLU 有 3 个（$W_1, W_2, W_3$）。为保持参数量相当，实际使用时隐藏层维度从 $4d$ 缩小到 $\frac{8}{3}d$（约 2.67d）。

5  门控机制可视化

拖动侧边栏滑块，观察"内容分支"和"门控分支"如何共同决定最终输出。

交互 · 门控相乘过程

上方 = 内容分支 $xW_2$（原始信息）；中间 = 门控分支 $\text{Swish}(xW_1)$（0~1的门）；下方 = 两者逐元素相乘后的输出

门控的作用：当门控值为 0，该维度的特征被完全抑制；当门控值为 1，特征完整通过。介于 0~1 之间时是软性保留。这让模型能根据输入上下文动态调整信息流，比固定的 ReLU 截断更灵活。

6  激活函数全面对比

图示 · 各激活函数特性对比

同时显示 ReLU、GELU、Swish 及其梯度。注意 Swish 在负区间有非零梯度，解决了 ReLU 的"死亡"问题。

ReLU FFN

• 负值直接截断为 0

• 梯度在负区间为 0（神经元死亡风险）

• 单分支，无门控

原始 Transformer, BERT, GPT-2

SwiGLU FFN

• 负值有小的非零输出（平滑）

• 梯度全程非零，训练更稳定

• 双分支门控，自适应特征选择

LLaMA, PaLM, Mistral, Qwen

为什么 SwiGLU 更好？实验表明 SwiGLU 在语言模型上始终优于 ReLU 和 GELU，PaLM 论文称之为"我们所尝试的激活函数中最好的"。理论上，门控机制增加了网络的表达能力，允许模型对不同的输入做非线性自适应处理，而不仅仅是固定的截断或平滑。
