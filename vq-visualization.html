VQ-VAE 在 Encoder 输出 z_e 与 Decoder 之间插入单层向量量化层，将连续向量映射到离散码本中最近的码字 e_k。

量化操作
\[ z_q = \arg\min_{e_k \in \mathcal{C}} \| z_e - e_k \| \]
总损失（Straight-Through Estimator）
\[ \mathcal{L} = \underbrace{\|x - \hat{x}\|^2}_{\text{重建}} + \underbrace{\|\text{sg}(z_e) - z_q\|^2}_{\text{码本}} + \beta\|z_e - \text{sg}(z_q)\|^2 \]

由于 argmin 不可微，梯度通过 straight-through 直接从 z_q 复制到 z_e，跳过了 VQ 选择步骤——这是 codebook collapse 的根源。

⚠️ Codebook Collapse 根因
\[ \frac{\partial \mathcal{L}}{\partial e_k} = 0 \quad \text{当 } e_k \text{ 未被选中时（死亡码字无梯度）} \]
💡 为什么重建损失救不了坍缩？

重建损失的梯度路径：decoder → straight-through → z_e → 码本损失 → 活跃码字。死亡码字对重建损失完全透明，梯度永远流不到它们。坍缩的本质是码字更新机会严重不均等——活跃码字越来越活跃，死亡码字原地不动，马太效应。

残差量化原理

RQ-VAE 引入多层残差量化：第 1 层量化原始向量，后续每层量化上一层的残差误差，逐步逼近原始表示。每层在独立的空间中操作，残差分布越来越集中在原点附近。

第 1 层
\[ z_q^{(1)} = \arg\min_{e_k} \| z_e - e_k \|, \quad r_1 = z_e - z_q^{(1)} \]
第 l 层（l ≥ 2）
\[ z_q^{(l)} = \arg\min_{e_k} \| r_{l-1} - e_k \|, \quad r_l = r_{l-1} - z_q^{(l)} \]
最终 Item ID
\[ \text{ID} = (k_1^*, k_2^*, k_3^*) \]

每个 item 获得一个 L 级 token 序列，量化精度随层数递增。但每层码本独立面临 collapse 风险，多层联合训练更难稳定。

⚠️ RQ-VAE 的代价

理论表达能力最强，但每一层都可能独立发生 codebook collapse，实践中需要 EMA 更新、codebook reset、K-Means 预热等多种 trick，工程复杂度高，且与 RQ-KMeans 的效果差距有限。

固定预训练 Encoder（BERT/CLIP 等），直接在其输出 embedding 上逐层做 K-Means 聚类，完全不需要梯度反传。每层对上一层的残差独立聚类。

K-Means 目标
\[ \min_{\mathcal{C}} \sum_{i} \| r_{l-1}^{(i)} - \text{nearest}(r_{l-1}^{(i)}, \mathcal{C}_l) \|^2 \]

K-Means 目标函数就是量化误差本身。由于 z_e 分布固定，每个聚类中心天然有数据点覆盖，码本利用率接近 100%，无 collapse 问题。

💡 核心洞察：换空间是手段，不是目的

当预训练 embedding 已是高质量低维连续语义空间时，encoder 换空间带来的收益接近零，引入的训练风险反而更大。RQ-KMeans 是"去掉 decoder、固定 encoder、直接最小化量化误差"的极简 RQ-VAE，在推荐场景中目标更直接、训练更稳定、工程更友好。

VQ-VAE 适用场景

✅ 原始特征维度极高（如图像像素），需大幅降维

✅ 任务目标与预训练表示不一致，需任务相关编码

❌ 单层量化精度不足，不适合推荐场景直接使用

RQ-VAE 适用场景

✅ 原始特征空间结构差（稀疏 ID），需联合学习表示与量化

✅ 可接受两阶段训练（先预热 encoder）

❌ 需配合多种 trick 防止 collapse，调参复杂

RQ-KMeans 适用场景

✅ 已有高质量预训练 embedding（BERT/CLIP 等）

✅ 百万级 item 全量稳定编码

✅ 工程要求简单、可复现、离线固定

✅ 推荐场景首选方案

📐 推演路径：从 RQ-VAE 到 RQ-KMeans 的自然推导

问题：RQ-VAE 训练不稳定（codebook collapse） → 方案1：两阶段训练，先训 AE 再插 VQ，用 K-Means 初始化码本 → 方案2：固定预训练 encoder，只训码本和 decoder，z_e 分布稳定 → 方案3（极限）：去掉 decoder，直接最小化量化误差 → 结论：这就是 RQ-KMeans。

K-Means 的目标函数本身就是量化误差，是在直接优化真正想要的目标，而 RQ-VAE 通过重建损失间接优化。既然能在同一个空间拟合 embedding 分布，就没必要换个空间拟合——换空间是手段，不是目的。
